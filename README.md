# MACK-DB — private code review snapshot

This checkout contains the **84 accepted scientific scripts** (35 main,45 supplementary,4 retained tests), their required local helpers, path-only configuration templates and bounded synthetic tests. All84 scripts are byte-identical to accepted v0.2; EPI qecdf v3 and DKI **MACKDB_DKI_R_20261012_v1** remain unchanged. The old full-qtrn Lowmem definition is not a default scoring entry.

## Run the lightweight tests

Use an existing compatible Python and R environment from [INSTALL.md](INSTALL.md):

```bash
python tools/verify_private_checkout.py
python tests/run_small_tests.py --rscript "$(command -v Rscript)"
```

The nine test groups actually passed in this independent checkout on2026-10-19. They exercise Profile, EPI core/workers/2-of-3, Zi-Pi roles, unified-R DKI scoring/selection, Figure3 sets and FastSpar postprocessing. Inputs are synthetic and generated by the retained test code. Small input/output examples are in tests/fixtures/; expected assertions are in the test source. No neural training, network optimization, large bootstrap or full cohort is run. Generated results/logs are ignored by Git. See [TESTING.md](TESTING.md).
