# Environment-level association support

This stage consumes significant project links and exact project coefficient/P inputs; it does not run any keystone method. Use environment `.list` files with unique project IDs. `link_to_project.py -l ENV_LIST -d LINKS -o OUT -n human_gut_core_links -f 2 -s T` writes four-column belonging tables and retains support from≥2projects. `get_link_info5.py` annotates the filtered file using `--tool fastspar`, `-c CORR_CSV_DIR`, `-a ABUNDANCE_DIR`; main derives environment from the exact `_core_links_filtered.belonging` suffix. `--source` is currently inactive in main.

**BLOCKED for unattended output acceptance.** Silent exceptions can omit coefficients/P while retaining project IDs/counts/sample counts, causing misaligned vectors; advertised ccl_coun/ccl_freq modes are not implemented. Five-decimal pre-rounding and final rounding match the archived reproduction function, but small P may become0 and tiny correlations can change at the rounding boundary. This source is unchanged. Prevalidate complete files, finite values, unique project membership, edge existence, equal-length aligned vectors and environment labels. These are actual synthetic diagnostics, not a finding of corrupted formal data. See the repository quality audit linked from PIPELINE.

fastCCLasso has dedicated `fastcclasso/link_to_project_fastcclasso.py` and `get_link_info_fastcclasso.py` readers. Do not select a ccl_* mode in the FastSpar reader. The separate reader checks missing edges and vector construction; duplicate support still requires caller validation. Output11columns retain project IDs, individual corr/P/sample vectors and mean correlation/P; these feed database evidence and literature comparisons, not EPI/DKI.
