# MetaKSSD: real one-Run FASTQ, Query and Profile

**PASS for the fixed ERR14036375 real paired-end Run**: actual FASTQ→counted Sketch→GTDB R226 Query→unchanged R Profile matches the archived scientific output; the five-species Profile is byte-identical. The [portable example](../../examples/real_fastq/ERR14036375/README.md) provides `data-info`, `preflight`, `run` and `verify` commands. Saved-Sketch routes retain separate **ARCHIVED_REPLAY** evidence; Profile also has synthetic tests. MetaKSSD2.21 is the pinned independent validation version, not a universal historical production claim.

The new `run_single_run.py` reads `config/single_run.local.json`; paths resolve from the JSON location, external executables can use PATH, and no Dell directory is required. It verifies two FASTQs, reference/core/executable hashes and version; uses short, owned scratch to protect native PATHLEN/popen behavior; invokes `dist -A -L SHUFFLE -p 1 -m 2`, composite and the original Profile core. Each external stage is bounded, failures retain evidence, outputs are committed only after reference checks, and cleanup is ownership-checked. It never downloads, installs, trains, invokes AWS or starts a batch.

Saved-Sketch inputs: ordered Run list, one compatible count Sketch per Run, externally obtained GTDBR226 MarkerDB/shuffle. `historical_linked_wrappers/query.sh REFERENCE SKETCH OUTPUT` runs the existing composite query. The accepted Query is headerless **seven-column** tabular data; R consumes X2 species label, X3 shared-k-mer count and X5 depth proxy. `profile.R -l RUNS -i QUERY_DIR -s 12 -o OUT` keeps X3≥12, applies the existing X5 lookup/subtract3 correction, normalizes to percentages and rounds4decimals. Output `RUN_profile.txt` is headerless label<TAB>percentage, consumed by abundance generation.

The number12 is shared-k-mer support, not k-mer length. Fixed L3K11 headers document22-mers/nominal1/4096, and all hashes are pinned. The [historical SRA stream](HISTORICAL_SRA_STREAM.md) is only a source-reviewed, nonexecuting plan; it is not PASS. The batch-matrix wrapper belongs to the next step. Fresh one-Run upstream validation,33Run archived matrices, frozen historical genus grouping and unverified DKI neural training remain separate scopes.
