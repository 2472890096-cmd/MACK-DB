# Keystone method concordance

concordance_release.py is the unchanged accepted numerical program formerly located at analysis/figures/figure3/figure3_release.py. It computes seven exclusive environment–taxon combinations, Broad/Strict support, ≥2 includingAll3, unique taxa and supporting projects. The final manuscript uses its1571 main and1570/1568 sensitivity scopes and accepted four-project unified-R DKI replacement.

CLI arguments and scientific assertions are unchanged. Run `python analysis/keystone_concordance/concordance_release.py --help` for implemented options and see ../../PIPELINE.md for the full frozen-input command. Input files and authorization limits are documented in ../../frozen_inputs/figure3/README.md. The synthetic FIGURE3_SETS test imports this module at its new path. No plotting or SVG patching is required for these statistics.
