# Lightweight test execution

From the checkout root, using an already available compatible environment:

```bash
python tools/verify_private_checkout.py
python tests/run_small_tests.py --rscript "$(command -v Rscript)"
```

Nine groups actually executed and passed in the clean upload directory on2026-10-19: PROFILE, EPI_CORE, EPI_WORKERS, EPI_2OF3, ZIPI_ROLES, DKI_R_SCORING, DKI_SELECTION, FIGURE3_SETS and FASTSPAR_POSTPROCESS. Timing/status is preserved without internal log paths in tests/expected/SMALL_TEST_RESULTS.tsv. Full execution logs are retained in the separate local preparation delivery, outside Git.

All synthetic inputs are generated by tests/run_small_tests.py and tests/unit/{epi,dki,zipi}.R. Numerical expected assertions and independent oracles are embedded in those unchanged files. tests/fixtures/synthetic contains24 tiny generated input/expected-output examples for inspection; its manifest records hashes and generator provenance. These examples are not real BioProject data and are not substituted for independent oracle calculations.

The tests validate Profile sharekmer12/Poisson boundaries, EPI25–75%/ECDF ties/first-jump fallback/D1/D2/Q/strict thresholds/legal zero/resume/2-of-3, fixed-module Zi/Pi sample-SD and roles, R-definition DKI q_null/Bray-Curtis/median/TopK/background thresholds, Figure3 exclusive Broad/Strict intersections and FastSpar edge cutoffs. The old Lowmem baseline counterexample is rejected by the R-scoring test. No full network optimization, neural training/prediction,10000 bootstrap inference, database access or cohort calculation occurs.

Generated outputs go to tests/results/<timestamp> and TEST_EXECUTION_RESULTS.tsv; both are ignored. Missing software is reported BLOCKED; execution failures are FAIL. Do not turn a missing dependency into a silent skip or report syntax checks as scientific execution. Optional external-validation and full frozen-real-data tests are outside this nine-group suite.
